# 

# \# Automatic Light Control Using LDR

# 

# \## Project Description

# This project uses an LDR light sensor

# to automatically control an LED using

# an Arduino Uno.

# 

# \## Components

# \- Arduino Uno

# \- LDR Sensor

# \- 10k Ohm Resistor

# \- LED

# \- 220 Ohm Resistor

# \- Breadboard

# \- Jumper Wires

# 

# \## Working

# 1\. The LDR detects surrounding light.

# 2\. Arduino reads the sensor every 1 second.

# 3\. If the environment is dark, the LED turns ON.

# 4\. If the environment is bright, the LED turns OFF.

# 

# \## Sensor Reading

# The LDR sensor is connected to analog pin A0.

# 

# \## Output

# The LED is connected to digital pin 9.

# 

# \## How to Run

# 1\. Open the project in Wokwi.

# 2\. Start the simulation.

# 3\. Change the LDR light level.

# 4\. Observe the LED response.

# 

# \## Tools Used

# \- Arduino Uno

# \- Wokwi Simulator

# \- Arduino C/C++
